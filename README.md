# Proj_Dashboard_Obras - Projeto desenvolvido com foco em análise de dados e Business Intelligence.
Este projeto consiste no desenvolvimento de um dashboard interativo no Power BI para análise de dados operacionais e financeiros de obras.
O painel permite acompanhar indicadores estratégicos (KPIs) como custo total, produtividade das equipes e desempenho das obras, facilitando a tomada de decisão.
## Principais análises:
- Monitoramento de custos por tipo (mão de obra, materiais e equipamentos)
- Análise de produtividade das equipes
- Acompanhamento da evolução dos custos ao longo do tempo
- Comparação entre obras
## Ferramentas utilizadas:
- Power BI
- Power Query
- Excel (como fonte de dados)
- DAX (para criação de métricas)
## Objetivo:
Transformar dados em informações claras e visuais, permitindo identificar oportunidades de melhoria e apoiar decisões operacionais.
